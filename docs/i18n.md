# Internationalization

## Locales
Current locale: `en`.

## Key convention
Use dot-separated namespaces:
- `common.*` for shared strings
- `storefront.*` for storefront-only strings
- `seller.*` for seller-only strings

## File layout
- Shared: `packages/config/i18n/en/common.json`
- Storefront: `apps/storefront/src/i18n/messages/en.json`
- Seller: `apps/seller/src/i18n/messages/en.json`

## Adding a string
1. Add the key to the appropriate JSON file.
2. Read it via `getTranslator(...)("namespace.path")`.

## Adding a language
1. Add `<locale>.json` in each app and shared config folder.
2. Update `locales` in each app's `src/i18n/index.ts`.

## Hard-coded string check
Run `pnpm check:strings`.

Use `i18n-ignore-next-line` on exceptional lines to suppress intentional literals.

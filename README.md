# Waslu Frontend

Monorepo for Waslu storefront and seller apps.

## Requirements
- Node.js 20+
- pnpm 12+

## Install
```bash
pnpm install
```

## Development
```bash
pnpm dev
```
- Storefront: http://localhost:3000
- Seller: http://localhost:3001

## Commands
- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`
- `pnpm build`
- `pnpm check:strings`
- `pnpm regen:api`

## Packages
- `apps/storefront`
- `apps/seller`
- `packages/ui`
- `packages/api-client`
- `packages/config`
